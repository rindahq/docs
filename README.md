# Rinda documentation — published site

This repository holds the **built** documentation site served at
[docs.rinda.dev](https://docs.rinda.dev) by GitHub Pages. It is generated:
every commit here is a publish from Rinda's main repository, and every file
is replaced on each one.

There is no source here to edit, so pull requests cannot be merged. To report
a mistake in the documentation, open an issue.

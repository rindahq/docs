redrive()​

redrive(options?): Promise<RedriveResult>

Defined in: libs/sdk/src/queue.ts:183

Moves messages from this queue's dead-letter queue back onto this queue, so they are delivered again.

Use this after fixing whatever made them fail. Their delivery count is reset, so a redriven message gets the queue's full allowance of attempts rather than being dead-lettered again on the first failure.

One call moves at most 500 messages and reports hasMore if the dead-letter queue still had messages when it stopped:

let result;
do {
  result = await queue.redrive();
} while (result.hasMore);

A message is put back before it is removed from the dead-letter queue, so a failure mid-redrive can deliver one twice but cannot lose one. Handlers should be idempotent, as they should be for any queue delivery.

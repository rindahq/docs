waitTimeSeconds?​

optional waitTimeSeconds: number

Defined in: libs/sdk/src/types.ts:81

How long to wait for a message, 0-20 seconds. Defaults to 20 — the call returns the moment a message arrives, so waiting costs nothing and saves a stream of empty round trips. Pass 0 for a non-blocking poll that answers at once, empty or not.

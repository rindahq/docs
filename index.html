Queues for your code and your agents

Managed message queues with FIFO ordering, dead-letter queues and object storage. Build with the SDK or the REST API, or hand it to your agent over MCP.

QuickstartAPI reference
Send your first message
// npm install @rindahq/sdk
import { Rinda } from '@rindahq/sdk';

const rinda = new Rinda({ apiKey: process.env.RINDA_API_KEY });
const orders = await rinda.queues.create({ name: 'orders' });
await rinda.queue(orders.id).send({ body: { orderId: 1 } });
